# SmartDine MVP Plan

## MVP Definition
The SmartDine minimal viable product (MVP) is the smallest working version of the system that basically proves the app can help a user in some way. In our case, a student can make a faster and more informed dining decision between classes. The MVP must allow the student to enter basic constraints, allow the system to evaluate a limited set of dining options, and display a useful ranked recommendation.

## MVP User Flow
1. Student enters schedule or available time information
2. Student enters nutrition goals and budget/swipe constraints
3. System loads dining hall, menu, and estimated wait-time data
4. System filters invalid dining options
5. System ranks valid options
6. System displays a one-sentence recommendation and ranked alternatives

## Included in MVP
- basic profile input
- schedule or free time input
- nutrition goal input
- dining budget or swipe input
- limited dining dataset
- limited menu dataset
- estimated wait time data
- filtering logic
- ranking logic
- one main recommendation
- ranked list of alternatives

## Excluded from MVP
- full live Google Maps integration
- full school account integration
- advanced learning behavior loop
- dining hall manager/admin account system
- complete campus-wide production deployment
