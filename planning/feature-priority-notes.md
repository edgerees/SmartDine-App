# Feature Priorities and Estimates

## Feature Priorities
Feature 1: Sentence Recommendation and User Feedback Interface  
Priority: Highest  
Reason: This is the main visible value to the student. Without a clear recommendation, the system does not solve the user’s problem directly.

Feature 2: Personalized Constraint Profile  
Priority: High  
Reason: Recommendations are only useful if the system understands the student's time, nutrition, and budget constraints.

Feature 3: Real-Time Environmental Data Collection  
Priority: Medium  
Reason: This improves recommendation accuracy, but the MVP can begin with limited or mock data before full live integration.

Feature 4: Multi-Source Optimization Engine  
Priority: High  
Reason: This is the core logic that transforms raw data into useful recommendations.

## Estimate Method
Effort estimates are determined at the feature level based on:
- implementation complexity
- dependency order
- testing time
- amount of backend and frontend coordination needed
