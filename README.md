# SmartDine-App
SmartDine is a decision-support system designed to help college students choose the most efficient and nutritionally appropriate dining option on campus at any given time.

## Project Overview
SmartDine is a decision-support system designed to help college students choose the most efficient and nutritionally appropriate dining option on campus at any given time. The system considers student schedule information, estimated congestion levels, menu availability, nutritional information, and dining budget constraints such as meal swipes or dining dollars. Using these inputs, SmartDine evaluates available dining choices and generates a ranked recommendation that helps students make faster and healthier meal decisions between classes and other commitments.

## Purpose of This Repository
This repo contains the planning, research, documentation, and implementation ideas for the SmartDine project. It is organized to support software engineering deliverables related to things such as, MVP planning, requirements engineering, user stories, Scrum sprint scheduling, project management, and future development.

## Minimum Viable Product (MVP)
The MVP for SmartDine is the smallest working version of the system that proves the core value of the product to students. In the MVP, a student can enter basic personal constraints such as their schedule, nutrition goals, and budget or swipe limits. The system then uses a limited dining dataset to filter and rank options, and presents the student a top recommendation along with a ranked list of alternatives. For the MVP we do not aim to have every functionality or all the bells and whistles but our goal is to have a working end-to-end recommendation workflow that directly benefits the student.

## Core Features
1. Recommendation and User Feedback Interface  
2. Personalized Constraint Profile  
3. Real-Time Environmental Data Collection
